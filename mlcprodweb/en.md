# MLCRemote

> [!CAUTION]
> **This project is retired.** MLCRemote has been officially superseded by **[MLCTerm](https://mlcgo.eu/products/mlcterm/)**. All development and security updates have moved to the new platform.

MLCRemote was an open-source, all-in-one remote development and system administration environment designed to be visual, fast, and free. It allowed developers and sysadmins to connect to Linux, Windows, or Mac from a native desktop application with zero complex setup.

## What it does

MLCRemote bridges the gap between expensive SaaS subscriptions and complex command-line utilities. It provides a visual interface for managing servers over SSH, deploying a lightweight, static Go binary automatically to handle operations. With its rich file manager, integrated terminal, and system monitoring tools, it offers everything needed to manage remote systems efficiently.

## Key features

- **Instant Access** — Connect in seconds; the app automatically deploys its own lightweight remote agent.
- **Rich File Manager** — Full support for Drag & Drop, context menus, trash, and bidirectional clipboard.
- **Terminal & PTY** — A native, resize-aware SSH terminal integrated directly into the workspace.
- **System Monitoring** — Real-time CPU, RAM, and Disk usage stats with visual health checks.
- **Media Previews** — Built-in viewers for Images, PDFs, Markdown, and Audio files.
- **Secure by Design** — All traffic is tunneled through standard SSH; no extra firewall ports are required.

## Successor: MLCTerm

If you are looking for a modern, actively maintained remote terminal and system management solution, please check out **MLCTerm**. It builds upon the foundation of MLCRemote with improved performance, a more robust architecture, and advanced features for modern development workflows.
